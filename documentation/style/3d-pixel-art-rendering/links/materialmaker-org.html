The open source procedural materials authoring tool

Create PBR materials using graphs where nodes create and transform textures. Export materials for use in game engines and movie assets.

 Get on itch.io    Get on Steam

Features

Node Based

With over 200 nodes available, new nodes can be created either by connecting and grouping existing nodes, or by describing them in GLSL.

PBR Materials

Effortlessly craft and export PBR materials compatible with the Godot, Unity and Unreal game engines, streamlining the game development process.

Community Library

Use the vast library of hundreds of materials, nodes, brushes and environments made by our community, for use in your projects or for studying how nodes work.

Texture Painting Tool

Texture 3D models with procedural brushes using the experimental painting tool.
